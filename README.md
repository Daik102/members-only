# Project: Members Only

A members only message app with several features<br>
This project is based on **[The Odin Project](https://www.theodinproject.com)**.

## Live Demo

**https://members-only-jp6x.onrender.com/**

> ⚠️ This project is hosted on a free Render tier. It takes roughly 20–30 seconds for the initial page load.

### Features

- User Authentication and Persistent Sessions

- Four-Tier Role Authorization (Visitor → Guest → Member → Admin)

- Admin dashboard for viewing registered users and managing promotions

- Server side validation

### Tech Stack

* **Frontend:** EJS, CSS, JavaScript

* **Backend:** Node.js, Express, Passport (passport-local), bcryptjs, express-validator

* **Database:** PostgreSQL, node-postgres (pg), express-session, connect-pg-simple

* **Deployment:** Render, Neon
